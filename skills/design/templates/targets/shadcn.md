# shadcn/ui

shadcn's theme variables are generated by `design build` from the `shadcn.vars` mapping in
`design.json`. Never edit them in `globals.css`; change a token or the mapping instead.

## Wiring

- `globals.css`: `@import "tailwindcss";`, then shadcn's `@theme inline` block, then
  `@import "<path to design/tokens.css>";`. shadcn's own `:root` and `.dark` blocks are deleted.
- `components.json` `aliases.ui`: <!-- @/components/ui --> (must equal `shadcn.import`).
- Copied components live in <!-- components/ui --> (must equal `shadcn.dir`).
- Dark mode: `themeSelector` `.{name}` and the `dark` theme file.

## Components

One spec per component a screen uses (`design new component <shadcn name>`); `check` rejects imports
of any other. Install with shadcn's CLI (`npx shadcn@latest add <name>`), never by hand.
